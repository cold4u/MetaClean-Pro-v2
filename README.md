# MetaClean Pro v2.1

Free, 100% browser-based privacy suite to strip EXIF, GPS location, camera details, and timestamps from images and videos.

- **Live Site**: https://cold4u.github.io/MetaClean-Pro-v2/
- **Features**:
  - 100% local processing (zero uploads, runs entirely in-browser)
  - EXIF / GPS / XMP / IPTC metadata stripping
  - Cyber Hacker extraction mode with live GPS telemetry & optics dossier
  - HEIC / HEIF format support
  - Embedded PWA support & offline caching
  - Clipboard paste support & batch queue processing
